# Get Wifi 7 Driver Support for Ubuntu 24, Realtek RTL8912 Chip (USB) | Tested ✔️
Run the [install-rtw89-wifi7.sh](./install-rtw89-wifi7.sh) script without sudo, and follow any instructions / provide sudo password when needed.

After installation, open the Ubuntu Settings app, go to Wifi tab, and you should see the new chip listed as a separate wifi.

## Wifi Multi-Manager
This repo also contains a Python GUI multiple wifi manager to add certain broken functionalities in Ubuntu's Gnome-Settings application for handling multiple wifi chips attached to the same device.
