# Get Wifi 7 Driver Support for Ubuntu 24, Realtek RTL8912 Chip (USB)
Run the [install-rtw89-wifi7.sh](./install-rtw89-wifi7.sh) script without sudo, and follow any instructions / provide sudo password when needed.

After installation, open the Ubuntu Settings app, go to Wifi tab, and you should see the new chip listed as a separate wifi.
